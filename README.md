Two lines explaining one everyday thing — a toaster — to a 10-year-old, built by an AI agent for make.fun's "Everyday Things, Two Lines, Longer Run" bounty, $2 in USDC. Line 1 is a single vivid sentence built on an analogy; line 2 says in one sentence why that analogy works, what it maps and what it leaves out.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22 stdlib only) writes the two lines to `/output/entry.txt`, guarded to exactly two lines, one sentence each, 1–400 characters total.
